# B站一起看：独立浏览器扩展

无需油猴，扩展中已包含全部同步代码。支持桌面 Chrome、Edge 和兼容 Manifest V3 的 Chromium 浏览器。与油猴版使用同一个中继，可以混合加入房间。

## 安装

1. 下载发行版 ZIP 并解压到固定目录，不要删除这个目录。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 打开右上角“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择包含 `manifest.json` 的目录。安装包根目录即为扩展目录；从源码仓库安装时选择 `extension` 子目录。
5. 刷新已打开的 B 站视频页面，页面右下角会出现“一起看”图标，默认不展开，点击后才打开面板。也可从浏览器工具栏点击扩展按钮展开。

这是可手动安装的扩展包，尚未提交 Chrome/Edge 商店；不能通过双击 ZIP 安装。以后更新时下载新 ZIP、解压替换原目录，再在扩展管理页面点击刷新，并刷新 B 站页面。

## 使用

所有参与者安装扩展版或油猴版。打开同一视频，创建房间并复制邀请。要一起换片，先勾选“持续同步：换视频也一起打开”，然后复制新邀请；接收人会自动加入持续同步模式。点击退出即可停止。支持稍后再看、分 P、具体 ep 番剧单集、倍速、暂停与进度同步。面板展开后闲置 5 秒隐藏，可关闭自动隐藏。

如果已安装油猴版，请停用那个脚本，避免两个实例同时控制视频。

## 权限与隐私

- `storage`：仅在扩展本地保存邀请码和自动隐藏偏好。
- `clipboardWrite`：点击复制邀请时写入邀请链接；不读取剪贴板。
- 内容脚本只在 B 站播放页及稍后再看页面运行；不请求全站访问、历史记录、Cookie 或后台控制其他标签页的权限。
- 连接 `wss://wilder.asia/bili-together/ws` 中继房间、视频编号及播放状态；不传输视频文件或 B 站账号信息。中继可见网络连接信息，房间状态仅在内存保存，空房清除。
- 持续模式会在已加入的当前标签页打开其他成员选中的 B 站视频，使用页面会话存储续接；不会强制控制其他未参与标签页。

## 开发

在仓库根目录执行 `npm run build:extension`，从用户脚本源码生成扩展的 `content.js` 和 `manifest.json`，不依赖任何用户脚本管理器。`npm test` 包含扩展适配和共享播放逻辑测试。修改共享播放逻辑后重新构建扩展。
